# Security Policy

Written provides a terminal and web interface for interacting with SDLC data
managed by Writ.

## Reporting a vulnerability

Please report suspected vulnerabilities privately, using GitHub's
[private vulnerability reporting](https://github.com/writtendev/written/security/advisories/new)
for this repository, rather than opening a public issue. This lets us
confirm the report, work on a fix, and coordinate disclosure before
details are public.

Include what you would include in any good bug report: the affected
version or commit, reproduction steps, and the impact as you understand it.

We will acknowledge new reports within a few business days.

## Scope

In scope: the CLI, TUI components, web server, and application wiring —
anything in this repository.
